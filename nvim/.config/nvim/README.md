# My nvim configuration

Just my personal on using neovim workflow configuration.

## pre-install

guarantee the following libs installed

- base-devel
- git, make, cmake, gcc
- lua, luarocks
- sqlite
- python, python-pip
  - `neovim`, `pynvim`
- fd, fzf, bat, rg, lazygit, unzip, curl, wget, yazi
- go
- rust, rust-analyzer, clippy
- nodejs, npm, pnpm
- marksman

and use `luarocks` to install following pkgs

```bash
luarocks install sqlite
```
