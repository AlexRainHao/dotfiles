# My nvim configuration

Just my personal on using neovim workflow configuration.

## pre-install

guarantee the following libs installed

- base-devel
- git, make, cmake, gcc
- lua, luarocks
- sqlite
- python, python-pip, python-pynvim
- fd, fzf, bat, lazygit, unzip, curl, wget, yazi, clippy
- go, rust, rust-analyzer, nodejs, npm 

and use `luarocks` to install following pkgs

```bash
luarocks install sqlite
```
